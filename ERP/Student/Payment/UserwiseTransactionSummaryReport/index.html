এই পেইজে যা যা পরিবর্তন/আপডেট করা হয়েছে
  1. Organization, Branch ও Campus মাল্টি-সিলেক্ট: তিনটি dropdown-এর উপরে Search box থাকবে; search করলে checked selection অক্ষুণ্ণ রেখে শুধু matching option দেখা যাবে। Organization ডিফল্টভাবে সব নির্বাচিত থাকবে। UDVASH-এর ১২৬টি এবং UNMESH-এর ১২৫টি Branch থাকবে; `Farmgate Udvash`, `Farmgate (GR) Unmesh` ও `Farmgate (MT) Unmesh` বাদ থাকবে। দুই Organization নির্বাচনে মোট ২৫১টি Branch alphabetical list-এ load হবে। Branch-এ Select All থাকবে না এবং View Report-এর জন্য শুধু এক বা একাধিক Branch নির্বাচন করতে হবে। Branch নির্বাচন হলেই সংশ্লিষ্ট Campusগুলো স্বয়ংক্রিয়ভাবে সব selected হয়ে Campus field-এ Select All দেখাবে; Campus আলাদাভাবে নির্বাচন বাধ্যতামূলক নয়। আংশিক নির্বাচনে একটি option-এর নাম বা “N selected” দেখাবে। সম্পূর্ণ filter combination অনুযায়ী report rows, Sub Total ও Grand Total দেখাবে।
  2. Organizationভিত্তিক আলাদা Report Section: UDVASH Branch-এর data শুধু UDVASH section-এ এবং UNMESH Branch-এর data শুধু UNMESH section-এ দেখাবে। দুই Organization-এর Branch নির্বাচন করলে উপরে–নিচে দুটি স্বতন্ত্র title, table, Sub Total ও Grand Total থাকবে; কোনো combined Organization title, row বা total থাকবে না।
  3. Organization-wise Demo Data Fallback: UDVASH-এর যেকোনো Branch নিলে একই পূর্ণ UDVASH sample dataset এবং UNMESH-এর যেকোনো Branch নিলে একই পূর্ণ UNMESH sample dataset দেখাবে। Selected Branch/Campus fixed demo rows কমাবে না; Farmgate-সহ source rows সবসময় থাকবে। একই Organization-এর একাধিক Branch data duplicate করবে না এবং দুই Organization-এর Branch নিলে আগের নিয়মে দুটি আলাদা section থাকবে।
  4. Filter change-এ report persistence: একবার View Report করলে Organization, Branch, Campus, User বা Date পরিবর্তনের সময় বর্তমান report auto-hide বা clear হবে না। নতুন filter নির্বাচন শেষে আবার View Report চাপলেই আগের report replace হয়ে নতুন selection-এর ফল দেখাবে।
