🔹 Written Script Splitting পেইজে উপরের দিকে কোন টাইপের কতগুলো খাতা এখনো পেন্ডিং আছে তা সামারি আকারে দেখাতে হবে।

🔹 Written Script Splitting পেইজে ডাটা টেবিলে Script Type কলামের পর Version নামে নতুন একটি কলাম যোগ করতে হবে। প্রতিটি Exam-এর ক্ষেত্রে দুটি Version-এর খাতা থাকলে — খাতাগুলো Version অনুযায়ী আলাদা করতে হবে, প্রতিটি Version-এর জন্য আলাদা Row আকারে দেখাতে হবে। একই এক্সামে একাধিক ভার্সন থাকলে Exam ও Script Type কলাম দুটি মার্জ করে দেখাতে হবে।
